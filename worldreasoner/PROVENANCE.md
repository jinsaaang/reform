# Provenance

This directory preserves the WorldReasoner source used by the finance DAG
construction workflow. It was recovered from the original study repository at
commit `f2b5e872` after the project directory had been renamed from
`research/worldreasoner` to `research/data_construction`.

The source, finance adapter, prompts, graph audit, search transports, and model
settings are retained together. ReFoRM adds only repository-level launchers
outside this directory.
