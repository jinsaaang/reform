# Provenance

This is the complete `hgf` source snapshot bundled with
`procedural_topology_hgf_canonical_v1_7_0_strict_20260804`. It is isolated from
the portable forecasting package so its Blueprint and exemplar generation
dependencies cannot be mixed with later packaging changes.

`scripts/build_hgf_artifacts.py` executes this snapshot with the fresh artifact
root supplied through `HGF_ROOT`.
